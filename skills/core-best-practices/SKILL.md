# 默认安全习惯

适用于所有项目。本 preset 已安装三个 hook 护栏(直推主干、危险 shell、密钥写入),编码时同步遵守:

## 主干保护

- 不在 `main`/`master` 上直接提交与推送;功能改动走 `feat/*`、`fix/*` 分支 + PR
- 强推远端前先停一下;确需覆盖时用 `--force-with-lease` 而非 `--force`

## 危险命令自查

- 执行 `rm -rf`、`dd`、`mkfs`、`curl ... | sh` 前,先确认目标路径与来源可信
- 清理目录优先用精确路径,不用 `*`、`.`、`..` 作为目标

## 密钥卫生

- 密钥/令牌只进环境变量或 secrets 管理器,不写进源码、配置、注释或日志
- 发现密钥已入库:立即吊销并轮换,再清理历史
